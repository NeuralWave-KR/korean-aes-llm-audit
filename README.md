# Reproduction — Surface Features, Not the LLM

Reproduction package for the paper *"Surface Features, Not the LLM: A Validity
Audit of an LLM-as-a-Judge Korean Essay Scoring Pipeline."* It regenerates every
quantitative result in the paper (Tables 1–7 and the headline QWK values) from
cached model inputs, with **no network access and no LLM API calls** at analysis
time.

> Anonymized for double-blind review. No author names or affiliations appear in
> this repository.

## What it reproduces

| Stage (`src/`)          | Outputs (`outputs/`)     | Paper                                   |
|-------------------------|--------------------------|-----------------------------------------|
| `e09_human_ceiling.py`  | `e9_human_ceiling/`      | Tables 1–2 · human ceiling QWK **0.584** |
| `e10_factorial.py`      | `e10_factorial/`         | Tables 3–4 · H2 (LLM increment) **+0.005 [−0.023, +0.032]** |
| `e7l_original.py`       | `e7l_original/`          | Audited original pipeline · **0.625** (test-selected) |
| `e11_honest_eval.py`    | `e11_honest_eval/`       | Table 5 · representative QWK **0.581** |
| `tables_6_7.py`         | `tables_6_7/`            | Table 6 (per-grade + CI) · Table 7 (gap decomposition) |

`verify.py` checks each regenerated number against the value reported in the
paper and exits non-zero on any mismatch.

## Repository layout

```
src/
  pipeline.py              shared feature construction, QWK, bootstrap (used by e10/e11/tables)
  e09_human_ceiling.py     human inter-rater ceiling (reads raw per-rater scores)
  e10_factorial.py         2^4 factorial attribution of information sources
  e7l_original.py          the audited pipeline, test-selected post-processing (0.625 arm)
  e11_honest_eval.py       same model, validation-based selection (0.581 representative score)
  tables_6_7.py            per-grade CIs + 0.625->0.581 label-vs-protocol decomposition
  preprocessing/
    prompts.py             the exact GPT-4o scoring prompt
    openai_rater.py        the GPT-4o rating client (temperature 0, seed 42, gpt-4o-2024-08-06)
run_all.py                 run all five stages in order
verify.py                  assert regenerated outputs == reported values
requirements.txt
data/                      (git-ignored — see "Data" below)
outputs/                   (git-ignored — regenerated by run_all.py)
```

## Data

The analysis reads two cached inputs, plus the raw archive for the human ceiling:

- `data/splits/{train,val,test}.csv` — essays + averaged expert scores (5,240 essays; 3,668 / 786 / 786).
- `data/gpt4o_ratings/{train,val,test}_gpt4o_ratings.csv` — cached GPT-4o ratings.
- `data/raw/aihub-essay/**/ *글짓기.zip` — raw AI-Hub labels with **per-rater** scores, required only by `e09_human_ceiling.py`.

**These files are not distributed here.** They are derived from the AI-Hub
dataset *"에세이 글 평가 데이터"* (`dataSetSn=545`), whose terms do not permit
redistribution. To reproduce:

1. Obtain the dataset from AI-Hub (registration/approval required) and place the
   `글짓기` archives under `data/raw/aihub-essay/…` following the paths above.
2. Build `data/splits/` and `data/gpt4o_ratings/`:
   - Splits are a grade-stratified 70/15/15 split of the 글짓기 essays.
   - GPT-4o ratings are produced by `src/preprocessing/openai_rater.py`
     (model `gpt-4o-2024-08-06`, `temperature=0`, `seed=42`, deterministic
     greedy decoding; prompt in `src/preprocessing/prompts.py`). This step needs
     the `openai` package and an API key, and incurs API cost.

Because the hosted model can drift or be retired, the **cached ratings are the
canonical inputs for exact reproduction**; regenerating them may differ slightly
if the API response changes.

## Environment

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
# optional, only to regenerate GPT-4o ratings from scratch:
# pip install openai tqdm
```

Python 3.11+. Pins in `requirements.txt` match the environment used for the
paper (numpy 2.2.6 / pandas 2.2.3 / scipy 1.15.2 / scikit-learn 1.6.1 / xgboost 2.1.4).

## Run and verify

```bash
python run_all.py     # ~10 min, CPU only, no network
python verify.py      # prints a paper-vs-repro table; exit 0 == all match
```

## Determinism

All learning uses fixed seeds (XGBoost seeds `42,123,456,789,2024`; bootstrap
seeds `11`/`42`). Point estimates are deterministic; bootstrap CIs are
reproducible bit-for-bit given the same seed and package versions. Minor
last-digit differences can arise only from BLAS/thread nondeterminism in XGBoost
on a different CPU.
